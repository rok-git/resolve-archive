# resolve-archive

macOS のフォルダを ZIP にする CLI です。symbolic link と Finder のエイリアスを解決し、リンクの代わりに実体を収録します。元ファイルは変更しません。

## ビルド・実行

macOS と Xcode Command Line Tools（`xcrun swiftc`）が必要です。

```sh
make
./build/resolve-archive -- '/path/to/対象フォルダ'
./build/resolve-archive --output '/path/to/保存先.zip' -- '/path/to/対象フォルダ'
```

省略時は入力の隣に `対象フォルダ.zip` を作成します。ZIP の最上位には入力フォルダ名が入ります。成功時は保存先を標準出力へ出し、失敗時は標準エラーへ理由を出して終了コード 1 を返します。既存の出力（壊れた symbolic link を含む）は上書きしません。保存先の親フォルダは事前に作成してください。入力フォルダ内への保存はできません。

## フォルダへのリンクの扱い

リンク先がフォルダなら、**リンク名を保った通常フォルダとして、中身を再帰的に収録**します。例えば `対象/資料リンク → /外部/資料` は、ZIP 内では `対象/資料リンク/（資料の中身）` になります。リンク先の中にあるリンクやエイリアスも解決します。

- 元フォルダの外にあるリンク先も取り込みます。共有・送付前には、取り込む外部データの範囲を確認してください。
- 同じ実体を複数のリンクが指す場合、それぞれにコピーします。重複排除はしません。
- 循環参照、リンク切れ、解決できないエイリアス、読み取り失敗、FIFO・ソケット・デバイス等は、全体をエラーにします。黙って除外しません。
- エイリアス解決時の UI 表示とボリュームの自動マウントは行いません。必要なディスク・共有はあらかじめ接続してください。
- 隠しファイル・空フォルダ・パッケージ内部も対象です。パッケージの中もリンクを展開するため、アプリ等の署名や動作を保持するバックアップ用途には適しません。
- 通常ファイルは Foundation でコピーし、`ditto` で macOS のリソースフォーク等を ZIP に収録します。ディレクトリは新規作成し、通常のアクセス権と更新日時を引き継ぎます。ディレクトリの拡張属性・ACL や、ハードリンクの同一性の完全保存は目的としていません。
- 一時領域には展開後の実体全体、保存先ボリュームには ZIP 分（コピー方式では一時 ZIP と出力 ZIP の最大2個分）の空き容量が必要です。通常の終了・エラーでは一時データを削除します。強制終了や電源断では一時フォルダが残る場合があります。
- 実行中に元データを変更しないでください。ファイルシステムのスナップショットは作成しません。
- ZIP の確定にはまず同一ボリューム上のハードリンクを使います。非対応エラー（`ENOTSUP` / `EOPNOTSUPP` / `ENOSYS`、または `EXDEV`）の場合は、排他的に新規作成したファイルへコピーする方式に自動で切り替えます。NAS／SMB共有、exFAT 等でもハードリンクなしで直接保存できます。既存ファイル・symbolic link は、同時実行で出現したものも含めて上書きしません。権限エラーや通信エラー等はそのまま報告します。

## NAS 等への保存

通常は追加オプションなしで、自動切り替えを利用できます。

```sh
./build/resolve-archive --output '/Volumes/NAS/保存先.zip' -- '/path/to/対象フォルダ'
```

最初からコピー方式を使う場合は `--copy-output` を指定します。ハードリンク非対応が上記以外のエラーとして返る環境でも使えます。書き込み権限や接続の問題を回避するオプションではありません。

```sh
./build/resolve-archive --copy-output --output '/Volumes/NAS/保存先.zip' -- '/path/to/対象フォルダ'
```

コピー方式は最終名の ZIP を作ってから内容を書き込むため、**保存途中の ZIP がほかのアプリから見えます**。CLI の成功終了を待ってから利用してください。通常のコピー失敗では不完全な出力を削除しますが、強制終了・電源断・通信切断などで削除できない場合は残ることがあります。残ったファイルは確認して削除するか、別の出力名で再実行してください。

## Finder の Quick Action

1. `make install` で `~/.local/bin/resolve-archive` にインストールします。別の場所には `make install PREFIX=/任意の場所` を使います。
2. Automator で「クイックアクション」を作成します。
3. 受け取る項目を「フォルダ」、対象を「Finder」に設定します。
4. 「シェルスクリプトを実行」を追加し、シェルを `/bin/zsh`、入力の引き渡し方法を「引数として」にします。
5. `scripts/finder-quick-action.zsh` の内容を貼り付けて保存します。インストール先を変えた場合は `archiver` も修正します。

Finder で選択したフォルダごとに、その隣へ ZIP を作成します。複数選択では順番に処理し、失敗した時点で停止します。それ以前に完成した ZIP は残ります。Quick Action の登録と CLI のインストールは自動では行いません。

## 検証

```sh
make test
```

Python 3.11 以降を使用します。実際の macOS エイリアスを生成し、外部のファイル・フォルダ、symbolic link とエイリアスの混在、循環、リンク切れ、上書き防止、日本語名、隠しファイル、空フォルダ、実行権限を確認します。

保存処理のテストではハードリンク非対応を模擬し、自動切り替え、強制コピー、同名ファイル作成の競合、書き込み途中の失敗時の削除も確認します。実際の NAS／SMB サーバーに対する接続テストは含みません。
